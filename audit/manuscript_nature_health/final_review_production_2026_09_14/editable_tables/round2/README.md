# Editable manuscript tables

This candidate package contains 19 individual Word documents, one real table per document. The main manuscript uses images of the accepted table displays; these separate files retain editable cells and the original embedded distribution plots.

Table 2 and Table S2 are newly exported from the verified integrated candidate HTML. The other 17 documents are exact copies of their previously accepted native documents, not newly rendered or re-exported tables. Their identity-bound complete-page visual checks are retained in export_provenance.json. Current output identities, dimensions and text checks are in table_manifest.json.

Tables use Arial with single-spaced cells, repeated table headers, native shading and explicit column widths. Table S2 uses A3 landscape to retain all 14 columns, the distribution plots, and complete mean ± SD units. No scientific value, label, note or figure content was recalculated.

These are review candidates. Full-page visual QA and independent acceptance are recorded outside this editable-table ZIP, in the enclosing candidate-production package.
