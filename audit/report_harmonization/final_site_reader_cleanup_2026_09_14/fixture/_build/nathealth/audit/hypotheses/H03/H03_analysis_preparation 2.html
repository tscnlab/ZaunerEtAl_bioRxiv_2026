From verified one-hour records and reported light sources to site-standardized exposure contrasts

Published

August 10, 2026

NoteAbout this analysis record

This page explains how verified one-hour melEDI records and normalized self-reported primary-light-source categories were turned into the H03 results. The companion H03 results report presents the scientific findings.

Rendering this page recalculates only current file identities, schema and key checks, and lightweight descriptive summaries from the frozen H03 model frames. It reads model estimates, confidence intervals, omnibus tests, diagnostics, influence refits, sensitivity results, exploratory smooths, and latitude results from their recorded files. It does not fit or refit a model, calculate predictions, re-estimate residual autocorrelation, rerun a leave-one-site-out analysis, bootstrap, simulate data, or recalculate a variance allocation.

Purpose

H03 asks whether all seven prespecified self-reported primary-light-source categories are associated with measured one-hour personal light exposure. Near-eye melEDI is primary; chest melEDI is complementary. The central estimand is the site-standardized geometric expected melEDI for each category and its ratio to indoor electric light. “Site-standardized” means that each included site contributes the same weight on the fitted log-mean scale, followed by one back-transformation.

This page identifies the data and code that produced the result, explains why each analytical operation was needed, and shows the recorded evidence used to check it. The analysis is observational and does not identify causal effects, health outcomes, or equivalence between measurement placements.

3. Primary model construction and inference

Additive population-mean model

The prespecified primary question is tested with a population-mean GLM:

geo_medi_1h ~ site + light_source

geo_medi_1h is the one-hour zero-aware geometric melEDI in lux. The model uses a log link and a quasi-Tweedie variance function Var(Y | X) = phi * mu^1.539919. Site is a fixed factor with sum contrasts; light source is a fixed seven-level factor with indoor electric light as the treatment reference. The formula contains no random effect. Repeated participant-hours are addressed for inference with participant-clustered HC1 sandwich covariance, finite denominator degrees of freedom equal to the number of participant clusters minus one, and two-sided 95% confidence intervals.

Cluster-robust covariance protects coefficient uncertainty against unspecified within-participant dependence under its large-cluster assumptions; it does not remove serial structure from residuals or change the fitted conditional mean. Participant-day repetition and within-day temporal dependence are therefore also examined directly in diagnostics and sensitivity analyses.

Omnibus test, category contrasts, and standardization

The primary omnibus is a six-restriction Wald F test that all six non-reference light-source coefficients equal zero. The near-eye test is the preregistered primary inference; the chest test is complementary. The six non-reference ratios to indoor electric light form one Benjamini–Hochberg (BH) family within placement. Category means and ratios average sites equally on the fitted log-mean scale and are back-transformed once; this is a site-standardized geometric expectation, not the arithmetic mean of response-scale site predictions.

6. Exploratory temporal and latitude context

Time-of-day GAMs

The time-of-day analysis is exploratory and separate from the preregistered GLM inference. geo_medi_1h ~
  s(time_hour, bs = "cc", k = 12) +
  s(time_hour, light_source, bs = "sz", k = 12) +

Participant, participant-day, and site smooths remain in the fitted model but are excluded from the displayed population curves. ## Purpose

H03 asks whether all seven prespecified self-reported primary-light-source
categories are associated with measured one-hour personal light exposure.
Near-eye melEDI is primary; chest melEDI is complementary. The central
estimand is the site-standardized geometric expected melEDI for each category
and its ratio to indoor electric light. “Site-standardized” means that each
included site contributes the same weight on the fitted log-mean scale,
followed by one back-transformation.

This page identifies the data and code that produced the result, explains why
each analytical operation was needed, and shows the recorded evidence used to
check it. The analysis is observational and does not identify causal effects,
health outcomes, or equivalence between measurement placements.

## 3. Primary model construction and inference

### Additive population-mean model

The prespecified primary question is tested with a population-mean GLM:

```r
geo_medi_1h ~ site + light_source
```

`geo_medi_1h` is the one-hour zero-aware geometric melEDI in lux. The model
uses a log link and a quasi-Tweedie variance function
`Var(Y | X) = phi * mu^1.539919`. Site is a fixed factor with sum contrasts;
light source is a fixed seven-level factor with indoor electric light as the
treatment reference. The formula contains no random effect. Repeated
participant-hours are addressed for inference with participant-clustered HC1
sandwich covariance, finite denominator degrees of freedom equal to the
number of participant clusters minus one, and two-sided 95% confidence
intervals.

Cluster-robust covariance protects coefficient uncertainty against unspecified
within-participant dependence under its large-cluster assumptions; it does
not remove serial structure from residuals or change the fitted conditional
mean. Participant-day repetition and within-day temporal dependence are
therefore also examined directly in diagnostics and sensitivity analyses.

## 6. Exploratory temporal and latitude context

### Time-of-day GAMs

The time-of-day analysis is exploratory and separate from the preregistered
GLM inference. It models the raw one-hour geometric melEDI outcome with a
fixed-power Tweedie mean, log link, global cyclic time smooth, sum-to-zero
light-source and site deviation smooths, participant-specific smooths, and
participant-day random intercepts:

```r
geo_medi_1h ~
  s(time_hour, bs = "cc", k = 12) +
  s(time_hour, light_source, bs = "sz", k = 12) +
  s(time_hour, site, bs = "sz", k = 12) +
  s(time_hour, participant, bs = "fs", k = 10) +
  s(participant_day, bs = "re")
```

The sum-to-zero smooths add category- and site-specific deviations to the
global cyclic time-of-day smooth; indoor electric light is not a smooth
reference. `bam()` used fREML, discrete computation, cyclic knots at 0 and 24
hours, and a second fit with an AR(1) working error parameter estimated from
the preliminary standardized residual lag-1 correlation. Participant,
participant-day, and site smooths remain in the fitted model but are excluded
from the displayed population curves. The stored figure curves average sites
equally and then omit unsupported time points from the display.

### Absolute latitude

clustered by site because latitude varies only between sites. Seven
