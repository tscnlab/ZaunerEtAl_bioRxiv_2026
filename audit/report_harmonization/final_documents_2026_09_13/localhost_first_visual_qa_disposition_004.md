## Default for future permitted automated inspection

Use the existing rendered output through the selected internal browser at an
exact `http://127.0.0.1:<port>/...` route. Do not begin with a file URL.

- Record source, configuration, HTML and rendered-resource identities first.
- Serve only the narrowest required rendered-output root, never the project
  root, credentials or raw research-data directories. Check symlinks before
  serving and reject any that escape the approved root.
- Use a temporary read-only GET/HEAD server bound strictly to `127.0.0.1`,
  with one recorded port, process and exact target at a time.
- Use existing HTML. Do not invoke Quarto preview, rerender or execute an
  analysis merely to inspect it.
- Obtain normal browser authorization where required. Inspect desktop,
  narrow and intended-final-size views, including clipping, wrapping,
  overflow, captions, notes, links and complete table/figure content.
- Stop on a browser policy rejection. Do not switch origins, browsers,
  automation surfaces or raw CDP to evade it.
- Stop the server, prove no listener remains, and rehash the protected output.
  A source/DOM check is not a substitute for visual inspection.

This is the project default, not a new render, capture or production budget.
Previously sealed target-specific scientific and execution boundaries apply.
