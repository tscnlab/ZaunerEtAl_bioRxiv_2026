From verified personal light-exposure metrics to reported results

Last modified:

August 14, 2026

About this analysis record

H01 asks whether personal light exposure differs among study sites. The analysis treats the near-eye sensor position as primary because it samples light closer to the eyes during wear, while recognizing that it does not directly measure retinal exposure. The chest sensor position provides complementary evidence about light measured at the chest, not ocular exposure. The 17-response package includes melanopic equivalent daylight illuminance (melEDI), an illuminance weighted for melanopsin-related sensitivity, and distinguishes an overall site association from photoperiod and absolute latitude.

This record explains which data and code produced those results, why each operation was needed, what it contributed, and what evidence shows that it behaved as intended. The sections follow the data-to-result sequence.

A model frame is the exact set of rows and variables used for one fitted model. Each response-specific frame is fixed before that model is fitted.

The H01 results report presents the scientific findings and its linked registration-record summary. Model estimates and 95% confidence intervals (95% CIs), model checks, influence results, and joint-refit summaries are read from stored outputs. This page does not fit or compare models, regenerate predictions, or repeat resampling.

False-discovery-rate (FDR) adjustment is applied separately to each of four complete 17-test families. A participant-day is one participant contributing one retained daily record on one local calendar day under the H01 day definition. Where a site-average estimate is reported, it is an average across sites that gives each site equal weight.

1. Data entering the analysis

Verified inputs

Two prepared datasets enter the analysis. The primary dataset could be interpreted as a time-sensitive primary metric dataset because the timing of remaining missing observations is used where it matters for the metric. The alternative dataset still passed the general 50%-per-hour and 80%-per-day coverage rules, but it does not use the timing of remaining missing observations for metric-specific adjustment. It is therefore called the gap-timing-unaware dataset below; the name does not mean that gaps, missingness, or coverage were ignored.

The metric definitions are documented in Preparation 04, and the model-ready dataset construction is documented in Preparation 06.

What these files contain

Each H01 analysis dataset contains the 17-metric contract, long model rows, sample flow, exclusions, predictor centres, scenario availability, a variable dictionary, and input provenance. The primary long table contains 45,650 rows and 50 named fields. Its composite key is scenario, placement, sample definition, metric, site, participant, and local date when the outcome is daily. The construction code verifies uniqueness within the appropriate analytical unit before a model frame is written.

The model rows retain the original metric value and units, the response construct, the metric-specific support denominator when available, site and participant identifiers, photoperiod, latitude, and the centred predictors supplied to the models. Missing support is never converted to zero exposure.

Why prepared records did not enter every model frame

The same metric-availability rules are applied before the site and latitude models are constructed. The table counts primary-dataset records excluded from each placement’s all-available frame; it lists each record once by using the site-plus-photoperiod frame, because the corresponding latitude frame applies the same outcome-availability screen.

3. Model-frame and sample construction

Eight analysis scenarios

The same implementation creates two placements × two prepared datasets × two sample definitions. The all-available near-eye primary dataset is the primary analysis. Chest is fitted separately. Samples containing the same participants and participant-days at both sensor positions are called placement-matched samples. They support direct near-eye–chest comparison but remain separate, unpooled models.

4. Model construction

Exact formula set

The implementation uses ordinary Gaussian linear models for participant-level outcomes and Gaussian linear mixed models or Tweedie generalized mixed models for participant-day outcomes. Participant-day models include a participant random intercept, representing remaining between-participant variation after the reported predictors are considered. Site and latitude models are fitted separately so that a nine-level site factor is never interpreted as a single latitude coefficient.

The complete site model estimates site and photoperiod jointly. The reduced site model removes site; the reduced photoperiod model removes photoperiod. The latitude model substitutes centred absolute latitude, expressed per 10°, for the site factor while retaining the same photoperiod term. All comparison fits use maximum likelihood; final Gaussian mixed models are refitted with restricted maximum likelihood for coefficient and variance reporting.

Marginal R² is the variation represented by all fixed predictors. Conditional R² adds the participant random effect, and the participant-associated share is their difference for participant-day models. These term-specific contributions can overlap and must not be summed; latitude belongs to a separate same-frame model.

8. Limitations and qualifications

  • The observational design does not identify causal effects of site, photoperiod, or latitude.
  • Site and latitude are structurally linked because each site has one latitude; separate same-frame models address estimability but do not remove geographic confounding.
  • Near-eye measurements are primary but are not direct retinal measurements; chest measurements are complementary and are not ocular exposure.
  • Model-check warnings require response-specific interpretation even when the optimization and inferential fit remain acceptable.
  • Measurement-support hours were not retained for the gap-timing-unaware dataset and therefore remain unavailable rather than reconstructed.
  • Term-specific part-R² summaries can overlap and must not be added.

How to examine or reproduce H01

A reader can inspect the chain in four passes:

  1. compare h01_contract.R with the two pinned analysis-dataset manifests to confirm the 17 responses, eight runs, transformations, and formulas;
  2. compare the sample and retention displays above with model_rows.csv, sample_flow.csv, and H01_exact_samples_by_site.csv;
  3. follow the producing script and SHA-256 identity in each manifest, using the stored model, bootstrap, diagnostic, table, and source-data files; and
  4. read the H01 results report alongside its full-precision source tables rather than inferring numeric values from figure pixels.

Changes to shared metric preparation must be made upstream and propagated to every affected hypothesis. A display-only change can instead be made from the stored reporting objects without refitting the models or repeating the bootstrap.

## About this analysis record

H01 asks whether personal light exposure differs among study sites. The
analysis treats the near-eye sensor position as primary because it samples
light closer to the eyes during wear, while recognizing that it does not
directly measure retinal exposure. The chest sensor position provides
complementary evidence about light measured at the chest, not ocular exposure.
The 17-response package includes melanopic equivalent daylight illuminance
(melEDI), an illuminance weighted for melanopsin-related sensitivity, and
distinguishes an overall site association from photoperiod and absolute
latitude.

This record explains **which data and code produced those results, why each
operation was needed, what it contributed, and what evidence shows that it
behaved as intended**. The sections follow the data-to-result sequence.

A **model frame** is the exact set of rows and variables used for one fitted
model. Each response-specific frame is fixed before that model is fitted.

The [H01 results report](../../../notebooks/hypotheses/H01.qmd) presents the scientific findings and its [linked registration-record summary](../../../notebooks/hypotheses/H01.qmd#h01-preregistration-deviations).
Model estimates and 95% confidence intervals (95% CIs),
model checks, influence results, and joint-refit summaries are read from stored
outputs. This page does not fit or compare models, regenerate predictions, or
repeat resampling.

False-discovery-rate (FDR) adjustment is applied separately to each of four
complete 17-test families. A participant-day is one participant contributing
one retained daily record on one local calendar day under the H01 day
definition. Where a site-average estimate is reported, it is an average across
sites that gives each site equal weight.

### What these files contain

Each H01 analysis dataset contains the 17-metric contract, long model rows, sample
flow, exclusions, predictor centres, scenario availability, a variable
dictionary, and input provenance. The primary long table contains
`r format_count(nrow(main_rows))` rows and 50 named fields. Its composite key
is scenario, placement, sample definition, metric, site, participant, and local
date when the outcome is daily. The construction code verifies uniqueness
within the appropriate analytical unit before a model frame is written.

The model rows retain the original metric value and units, the response
construct, the metric-specific support denominator when available, site and
participant identifiers, photoperiod, latitude, and the centred predictors
supplied to the models. Missing support is never converted to zero exposure.

## 4. Model construction

### Exact formula set

The implementation uses ordinary Gaussian linear models for participant-level
outcomes and Gaussian linear mixed models or Tweedie generalized mixed models
for participant-day outcomes. Participant-day models include a participant
random intercept, representing remaining between-participant variation after
the reported predictors are considered. Site and latitude models are fitted
separately so that a nine-level site factor is never interpreted as a single
latitude coefficient.

## 8. Limitations and qualifications

- The observational design does not identify causal effects of site,
  photoperiod, or latitude.
- Site and latitude are structurally linked because each site has one
  latitude; separate same-frame models address estimability but do not remove
  geographic confounding.
- Near-eye measurements are primary but are not direct retinal measurements;
  chest measurements are complementary and are not ocular exposure.
- Model-check warnings require response-specific interpretation even when the
  optimization and inferential fit remain acceptable.
- Measurement-support hours were not retained for the gap-timing-unaware
  dataset and therefore remain unavailable rather than reconstructed.
- Term-specific part-R² summaries can overlap and must not be added.
