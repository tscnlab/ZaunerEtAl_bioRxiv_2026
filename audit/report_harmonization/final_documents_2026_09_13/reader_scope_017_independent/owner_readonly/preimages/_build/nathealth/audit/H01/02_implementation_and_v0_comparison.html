H01: Site differences in personal light exposure

Audited analysis and comparison with the submitted V0 results

Last modified:

August 1, 2026

ImportantProduction calculation baseline complete

Every estimable H01 target has at least 1,000 successful joint bootstrap refits. The tables below therefore use production intervals throughout.

Result in brief

The audited near-eye analysis retains the familiar 17-metric H01 package. Each metric is fitted with its declared response family, participant-day outcomes include a participant random intercept, and the four model-wide questions—site, photoperiod, latitude, and same-frame site-versus-latitude adequacy—are adjusted as four separate 17-test Benjamini–Hochberg families.

The response-family review changed only one metric: calendar-day cumulative time below 10 lx melEDI before sleep now uses a Gaussian identity model and is reported as an ordinary difference. The submitted-style Tweedie/log model was retained for time below 1 lx melEDI during sleep, and the shifted-log Gaussian model was retained for darkest-10-hour mean melEDI because no common alternative cleared the predefined diagnostic rule in both data scenarios and placements.

The additional support relative to V0 is concentrated in time above 250 lx melEDI during wake for site and latitude, and in the L10 midpoint for photoperiod. These are model-wide results, not nine separate site contrasts. The hierarchical site comparisons appear only for the eight metrics whose overall site test is supported.

Response-family decision

The candidate comparison used the identical implementation and model rows for the main and manuscript-prepared scenarios. Selection required the declared hard screens, common diagnostics, and all inferential fits to pass; descriptive random-site singularity was reported but was not allowed to redefine inferential eligibility.

The selected pre-sleep Gaussian model converged in all eight required runs, had no strong residual warning, and stayed inside the 24-hour physical bound. For the main near-eye fit its residual-variance ratio was 1.66. The calendar- day cumulative construct is not truncated: observations strictly above six hours remain valid and are reported as an audit warning.

Gate A and Gate B outcome checks

Gate A retains the calendar-day cumulative estimand for time below 10 lx melEDI before sleep. A calendar date can legitimately contain parts of two diary-defined three-hour pre-sleep intervals; therefore values are not capped at three hours. Values strictly above six hours trigger review without being removed or truncated.

Gate B retains a linear clock model. The primary conversion subtracts 24 hours only from L10 midpoint values strictly later than 16:00; the noon cut is the same-row, same-family sensitivity. These are bell-shaped linear responses in the fitted range, so no circular model is introduced.

Reconstructed Table S2

The submitted Table S2 combined model tests, fixed effects, nine site deviations, and random-effect summaries in one very wide bitmap. The faithful reconstruction below preserves its metric categories and questions but splits the content into three semantic tables: model-wide tests, effect estimates, and hierarchical site follow-ups. This allows 95% confidence intervals and both raw and adjusted p-values to remain readable.

Reconstructed Table S3: variation represented

Marginal R² represents the complete fixed-effect set; conditional R² represents fixed and participant random effects together. The participant-associated share is conditional minus marginal R² for participant-day models. Site and photoperiod part R² values are term-specific reductions in fixed-effect prediction variance and are deliberately not added because their information can overlap. Latitude part R² belongs to the separate latitude model.

Exact fitted samples

Every model reports its exact participants, participant-days, observations, sites, and main-data measurement support where the metric producer retained exact support minutes. Participant-level IS and IV have one model observation per participant but retain the contributing participant-day count. In the main data, exact support hours are unavailable only for the M10 and L10 mean and midpoint metrics because their producer did not export exact support minutes; they are not imputed. The manuscript-prepared sensitivity lacks reconstructable metric-specific support records for every metric, so all of its support hours remain explicitly unavailable.

Sensitivity and complementary analyses

The identical implementation is applied to the manuscript-prepared data. Near-eye remains primary, paired/common-sample analyses separate placement from availability, and chest remains complementary rather than pooled. The table summarizes how many of the 17 metrics are supported in each declared family; the full metric-level p-values remain in the linked source CSV.

Additional required checks are retained outside the four primary families: the noon-cut L10 analysis uses the same rows and Gaussian model, the longest- period analysis is repeated using only exactly identified bouts, latitude is refitted after omitting each site in turn, and participant influence is assessed by leave-one-participant-out refits. These sensitivity p-values do not enter the primary multiplicity families.

Figure S10: photoperiod and latitude

The reconstruction applies the submitted Figure S10 visual grammar to the new audited data: the original square layout, density ridges, vertically jittered points, black masks outside the theoretical civil-photoperiod envelope, in-panel legend, and white annotation are retained. The registered site order, names, and colours are unchanged. All points use the submitted circular symbol; sites sharing a colour remain distinguishable by their fixed north-to-south placement. The coloured observations and density ribbons are drawn in front of the black impossible-photoperiod masks.

Bootstrap execution record

The pilot used four parallel workers, one BLAS/OpenMP thread per worker, wrote all eight completed target checkpoints, and produced no failed or warning refit. The subsequently approved production run completed all eight changed targets in 310.9 seconds. Of 12,000 attempted refits, 11,996 succeeded and 8,000 were retained; four failed attempts were replaced before each target reached 1,000 successful joint refits. All 120 unchanged target draw hashes remained unchanged.

Claim consequences and unresolved items

The submitted broad conclusion that site differences are concentrated in level- and timing-based outcomes remains recognizable, but it needs revision: the audited analysis additionally supports an overall site effect for time above 250 lx melEDI during wake. The same duration metric also gains support for a latitude gradient. Photoperiod remains widely associated with duration, level, dose, spectrum, and selected timing metrics, and the L10 midpoint joins the supported photoperiod set. First light timing above 250 lx melEDI remains unsupported for site.

The site-versus-latitude adequacy family is new and must not be equated with a separate residual site effect after latitude adjustment. Site and latitude are competing fixed-effect representations of the same site-level structure in identical model frames.

The submitted R² percentages cannot be carried forward as additive variance contributions. The repaired marginal, conditional, participant-associated, and term-level part-R² summaries remain separate; site and photoperiod part R² are not summed. No response-family or bootstrap major-change gate remains open. Diagnostic WARN_REVIEW rows remain visible for model-level review and do not silently redefine the approved response families.

format_p <- function(value) {
  case_when(
    is.na(value) ~ "—",
    value < 0.001 ~ formatC(value, format = "e", digits = 2),
    TRUE ~ formatC(value, format = "f", digits = 3)
  )
}

format_number <- function(value, digits = 2) {
  ifelse(
    is.finite(value),
    formatC(value, format = "f", digits = digits),
    "—"
  )
}

format_clock <- function(value) {
  output <- rep("—", length(value))
  finite <- is.finite(value)
  minutes <- round((value[finite] %% 24) * 60) %% (24 * 60)
  output[finite] <- sprintf("%02d:%02d", minutes %/% 60, minutes %% 60)
  output
}

format_estimate_ci <- function(
  estimate,
  conf_low,
  conf_high,
  unit,
  effect_type = "difference"
) {
  output <- rep("—", length(estimate))
  finite <- is.finite(estimate) & is.finite(conf_low) & is.finite(conf_high)
  clock <- finite & unit == "clock time" & effect_type == "mean"
  output[clock] <- paste0(
    format_clock(estimate[clock]),
    " [",
    format_clock(conf_low[clock]),
    "–",
    format_clock(conf_high[clock]),
    "]"
  )
  numeric <- finite & !clock
  suffix <- ifelse(
    unit[numeric] %in% c("h", "lx", "lx·h"),
    paste0(" ", unit[numeric]),
    ""
  )
  prefix <- ifelse(effect_type[numeric] %in% c("ratio", "odds_ratio"), "×", "")
  output[numeric] <- paste0(
    prefix,
    formatC(estimate[numeric], format = "f", digits = 2),
    " [",
    formatC(conf_low[numeric], format = "f", digits = 2),
    "–",
    formatC(conf_high[numeric], format = "f", digits = 2),
    "]",
    suffix
  )
  output
}

format_r2 <- function(estimate, conf_low, conf_high) {
  output <- rep("—", length(estimate))
  finite_estimate <- is.finite(estimate)
  finite_interval <- finite_estimate & is.finite(conf_low) & is.finite(conf_high)
  output[finite_estimate] <- paste0(
    formatC(100 * estimate[finite_estimate], format = "f", digits = 1),
    "%"
  )
  output[finite_interval] <- paste0(
    formatC(100 * estimate[finite_interval], format = "f", digits = 1),
    "% [",
    formatC(100 * conf_low[finite_interval], format = "f", digits = 1),
    "–",
    formatC(100 * conf_high[finite_interval], format = "f", digits = 1),
    "]"
  )
  output
}

## Claim consequences and unresolved items

The submitted broad conclusion that site differences are concentrated in
level- and timing-based outcomes remains recognizable, but it needs revision:
the audited analysis additionally supports an overall site effect for time
above 250 lx melEDI during wake. The same duration metric also gains support
for a latitude gradient. Photoperiod remains widely associated with duration,
level, dose, spectrum, and selected timing metrics, and the L10 midpoint joins
the supported photoperiod set. First light timing above 250 lx melEDI remains
unsupported for site.

The site-versus-latitude adequacy family is new and must not be equated with a
separate residual site effect after latitude adjustment. Site and latitude are
competing fixed-effect representations of the same site-level structure in
identical model frames.

The submitted R² percentages cannot be carried forward as additive variance
contributions. The repaired marginal, conditional, participant-associated,
and term-level part-R² summaries remain separate; site and photoperiod part R²
are not summed. No response-family or bootstrap major-change gate remains
open. Diagnostic `WARN_REVIEW` rows remain visible for model-level review and
do not silently redefine the approved response families.
