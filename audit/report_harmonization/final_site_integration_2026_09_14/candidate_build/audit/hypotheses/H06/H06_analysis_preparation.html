H06 analysis preparation and provenance

  • Show All Code

From supported one-hour personal-light records and linked diaries to day-type, activity, and previous-sleep contrasts

Last modified:

August 14, 2026

This page records how the hourly H06 analysis was prepared. It follows melanopic equivalent daylight illuminance (melEDI) from observed hours that met the support criteria through the reported models and displays. A participant-hour is one observed one-hour interval from one participant that met the support criteria; a participant-day is one calendar day contributed by one participant. The near-eye sensor position is primary because it is closer to ocular light exposure. The chest sensor position is complementary and represents non-ocular exposure.

The Hourly H06 results report gives the associations, uncertainty, model checks, and interpretation.

The complementary participant-day report addresses daily light-exposure metrics. The hourly analysis remains the main H06 analysis, and the two estimands are not interchangeable.

NoteAbout this analysis record

This page reads the reviewed stored frames, tables, model-check outputs, figures, and file identities for display. It does not repeat model fitting or scientific computation. In particular, it does not fit or refit a model, generate model predictions, estimate residual correlation, rerun a sensitivity analysis, resample, or simulate.

Analysis path

The common-effect path estimates one association across sites. The predictor-by-site interaction path allows the association of day type, activity, or previous sleep with hourly melEDI to differ by study site.

Constructing the fitted samples

Outcome and analytical unit

The outcome is the zero-aware geometric mean melEDI for each retained participant-hour. The quantity remains in lux, exact zeros remain valid, and an hour is retained only after the upstream one-hour coverage rule is met. The model therefore estimates mean hourly melEDI among observed hours that met the support criteria; it does not estimate a daily light-exposure metric. Because participant-days contribute 19–24 supported participant-hours, days with more retained hours receive more weight.

The primary near-eye source contains 19,584 one-hour records. After outcome admissibility, work/free linkage, binary activity linkage, and preceding-sleep linkage, 16,596 hours remain. Activity is the largest source of exclusion. Missingness is handled by constructing an exact complete frame before fitting; model-specific row dropping is not left to the fitting function.

Day type, activity, and previous sleep

  • work_free_day is a participant-day diary label: Work day or Free day.
  • activity_status is Sedentary when no exercise was reported and Active when light, moderate, or vigorous exercise was reported. The four original intensity labels are not used as separate primary levels.
  • previous_sleep_duration_h is taken from the preceding eligible sleep period and centred at 8 h. The fitted coefficient is therefore the ratio for one additional hour of previous sleep.

Primary model and estimands

Exact formulas

The quasi-Poisson model estimates a log mean while allowing the response variance to differ from a Poisson variance. Study site enters as a fixed effect, so the model adjusts for the listed sites rather than treating them as a random sample of sites. A participant-cluster-robust 95% CI allows hours from the same participant to be related and uses the HC3 small-sample correction. The predictor-by-site interaction model allows an association to differ by study site. A site-average estimate gives each included site equal weight on the log scale, then back-transforms once to the reported ratio.

This page records how the hourly H06 analysis was prepared. It follows
melanopic equivalent daylight illuminance (melEDI) from observed hours that
met the support criteria through the reported models and displays. A
participant-hour is one observed one-hour interval from one participant that
met the support criteria; a participant-day is one calendar day contributed
by one participant. The near-eye sensor position is primary because it is
closer to ocular light exposure. The chest sensor position is complementary
and represents non-ocular exposure.

The [Hourly H06 results report](../../../notebooks/hypotheses/H06.qmd) gives
the associations, uncertainty, model checks, and interpretation.

The [complementary participant-day report](../../../notebooks/hypotheses/H06_daily.qmd)
addresses daily light-exposure metrics. The hourly analysis remains the main
H06 analysis, and the two estimands are not interchangeable.

## Primary model and estimands

### Exact formulas

The quasi-Poisson model estimates a log mean while allowing the response
variance to differ from a Poisson variance. Study site enters as a fixed
effect, so the model adjusts for the listed sites rather than treating them as
a random sample of sites. A participant-cluster-robust 95% CI allows hours
from the same participant to be related and uses the HC3 small-sample
correction. The predictor-by-site interaction model allows an association to
differ by study site. A site-average estimate gives each included site equal
weight on the log scale, then back-transforms once to the reported ratio.

The common-effect formula asks whether estimated mean hourly near-eye melEDI
among observed hours that met the support criteria differs for free versus
work days, active versus sedentary day status, and per one additional hour of
previous sleep. The null ratio is 1. Local clock time is not a primary
predictor. The predictor-by-site interaction formula allows each of those
three associations to differ by study site; it is not a different reference
outcome or a test of whether a site lies above the site-average association,
which gives each included site equal weight.

The quasi-Poisson specification is used as a log-mean estimating model, not as
a claim that the observed melEDI distribution is Poisson. A
participant-cluster-robust 95% confidence interval (95% CI) allows
observations from the same participant to be related and uses the HC3
small-sample correction. The site-average estimate gives each included site
equal weight and then back-transforms once; participant-hours do not determine
site weights.

The selected occurrence component uses all 16,596 primary hours; the positive
magnitude component uses 11,899 positive hours. Removing zeros splits some
positive-magnitude sequences, so residual correlation never bridges an
excluded zero. The working residual correlations are approximately 0.418 and
0.440. The AR(1) working structure relates residuals in adjacent supported
hours within a true-time sequence, with the working relation weakening across
larger lags. It is a GEE-like working adjustment for these non-Gaussian `bam`
fits, not a fully generative joint autoregressive likelihood.
