## Approved vocabulary and glossary content

- Define **melanopic equivalent daylight illuminance (melEDI)**, the primary near-eye sensor position, and complementary chest sensor position at first use; chest is not ocular exposure.
- Define **participant-day** wherever the denominator first matters.
- Introduce a **nonlinear GAM analysis**: a generalized additive model (GAM) allows the association between civil photoperiod and the named light metric to bend rather than follow a straight line. `GAM` and fitted curve may remain thereafter.
- Define the **derivative** as the slope of the fitted curve, describing how quickly the fitted outcome changes for each additional hour of photoperiod at each point. State explicitly whether the derivative is on the model scale and keep endpoint units visible.
- Define a **pointwise 95% confidence interval (95% CI)** as uncertainty at one photoperiod value; it is not a simultaneous band for the whole curve.
- Define the qualifying transition using the accepted three-part rule exactly: a preceding point with an interval wholly above zero, the next point with an interval containing zero, and zero-compatible derivative intervals through the recorded maximum. Do not paraphrase this into one non-significant derivative, visual flattening, a biological ceiling, a permanent plateau, or an equivalence claim.
- Explain `concurvity` in reader prose as **overlap among nonlinear model terms** that makes their separate contributions harder to distinguish. The technical term may remain after that explanation.
- Use **model checks** as the reader umbrella term; `model diagnostics` may appear once parenthetically or in technical detail. Explain residual autocorrelation as observations close in sequence retaining more similar residuals than observations farther apart.
- Explain transformed and response-scale curves; if `back-transformed` is used, first state that the fitted quantity was converted back to the displayed metric unit.
- Define each **sensitivity analysis** by the exact changed data definition, photoperiod smooth flexibility, site specification, or omitted site. Preserve that agreement concerns only the yes/no classification, not an identical transition point.
- Every reader-facing site name must carry its ISO alpha-2 country code in prose, tables, figures, legends, captions, and alt text, using `config/site_display_registry.csv` exactly. Internal codes may remain only in code/provenance.

The short glossary should precede the first dense curve/derivative display and contain only the concepts needed to read it.
